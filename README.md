# ZOS Drop Shop (CarFix-style site)

Static multi-page site inspired by [CarFix TNC](https://carfix-tnc.webflow.io/). Vite + HTML/CSS/JS.

## Run

```bash
npm install
npm run dev
```

Open the local URL (usually `http://localhost:5173`).

## Pages

Home, About, Services, Products, Blog, FAQ, Contact, Checkout, 404

## Swap branding

See `public/ASSETS.md`. Drop your logo / photos / video into `public/images` and `public/video`.

# Assets

## What we can / cannot grab

**Cannot** ship TNCFlow / Webflow demo CDN files (their logo, photos, video, paid CSS pack). That is copyrighted commercial template media.

**Can** recreate layout + styling in our own code, and use free stock (Unsplash) as temporary media.
